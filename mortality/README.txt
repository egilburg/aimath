RESULT
For n > 0, any family of real n × n matrices whose entire word-product monoid is finite and contains zero has a zero word of length at most b(n) = 2^(n−1) + (2^(n−1)−1)n(n+1)/2. The same dimension and word bound hold over the rationals. No finite-alphabet assumption is needed.

REPRODUCE
Install Git, Python 3 and Elan (https://github.com/leanprover/elan).
From this package root:

    sha256sum -c verification/SHA256SUMS
    cd lean
    elan toolchain install leanprover/lean4:v4.33.1
    lake exe cache get
    sh verify.sh

Retain the exact lake-manifest.json; do not update dependency versions.
The cache command is optional and obtains public dependency artifacts.
The verification script writes new results to ../recheck/ without replacing
the recorded verification supplement. See verification/README.txt for the
actual fresh build, audits, equivalence checks and runtime adaptation.
The public Mathlib dependencies are pinned; no old project build cache or
private repository is required by the extracted proof.

REBUILD THE MANUSCRIPT
With TeX Live and latexmk installed, run sh build_manuscript.sh.
The regenerated PDF appears under recheck/tex/.
