Sharp Finite Markov Order in Intrinsic Sofic Dimension
Lean development

Build and audit
---------------
Install the toolchain pinned by lean-toolchain, then run:

  lake exe cache get
  LAKE_ARTIFACT_CACHE=false lake build Publication
  lake env lean Audit.lean

verify.sh runs the build and endpoint axiom audit, placing fresh logs in
../recheck/. The accompanying verification/ directory records the verification
environment, hashes and the comparison with the previous public proof.
The script disables Lake's global artifact cache. For a full source rebuild,
also remove the current project's .lake/build directory before running it;
the pinned external dependency cache can be reused.

For the optional historical compatibility check, build the previous public
Lean package from commit 735383665b012b5b2d30450735ed062fde7bd030 of
https://github.com/egilburg/aimath, then run:

  ./verify.sh --compare /path/to/previous/sofic_markov_order/lean

That optional audit compares all four endpoint types and their custom
definition dependencies under the recorded renaming. The previous package
is not needed by the current proof's ordinary build or axiom audit.

Entry points
------------
Publication.lean imports the two final theorem modules. All paper declarations
are in the namespace SoficMarkovOrder.

  stationary_process_markov_cutoff_of_finite_hankel
    A stationary finite-alphabet probability process with finite real Hankel
    dimension n and some finite Markov order has Markov order at most n.choose 2.

  stationary_process_markov_cutoff_of_representation
    A finite linear presentation supplies the finite-Hankel hypothesis; the
    bound uses intrinsic dimension and requires no minimality assumption.

  exists_rational_sharp_sofic_process
    For every n >= 2, an actual stationary probability process has a nonnegative
    rational n-dimensional presentation, intrinsic Hankel dimension n and exact
    Markov order n.choose 2. The alphabet can depend on n. Its total transition
    is the uniform mean. The theorem includes the n = 2 boundary case.

  processMarkov_iff_rankOne
    For a reduced presentation of a stationary probability law, the finite-
    history conditional-probability Markov condition is equivalent to rank at
    most one for all products of the specified length, including forbidden
    words and order zero.

The ProcessMarkov definition uses cylinder events and conditional probabilities;
it does not define Markov order by matrix rank. sequenceShift is the usual left
shift on one-sided sequences. Word products act on column vectors, so the
rightmost letter in a product acts first.

------------------
Upper bound:
  WordProducts         Word products, reachable columns and their span.

Attribution and scope
---------------------
The word-level rank criterion is Holland's criterion, with source attribution
and the inspected reproduction specified in the manuscript. The pair-chain
core is Trahtman's 1998 construction, Section 6, in column-action convention;
Beal and Senellart (1998) provide the deterministic binomial-delay precedent.
The manuscript contains complete bibliographic information and distinguishes
these ingredients from the joined intrinsic stochastic result.

The two-sided extension comparison and historical identification of the
Trahtman matrices are manuscript arguments, not separate Lean endpoints.
The formal endpoints concern one-sided stationary processes. No optimal
fixed-alphabet size or computational efficiency claim is made.
